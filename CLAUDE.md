# Zahida Amina — Personal Portfolio

A fully responsive, single-page portfolio website for Zahida Amina (Computer Science graduate: web development, software QA, and design).

## Requirements
- Semantic HTML5 for all structural blocks: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`. One `<h1>`, an `<h2>` per section, an `<h3>` per card.
- Custom CSS Grid and Flexbox layouts.
- Fluid layout across all screen widths, using CSS media queries at 600px, 900px, and 1200px breakpoints, plus fluid techniques like `clamp()` and `auto-fit` grids.
- A smooth, interactive mobile navigation menu.

## Technical rules
- Plain HTML5, CSS, and vanilla JavaScript only. No frameworks, no build step.
- File structure: `index.html`, `css/styles.css`, `js/main.js`, `assets/`.
- Mobile-first CSS using custom properties (design tokens) for colors, spacing, and fonts.
- Accessible: skip link, visible focus states, ARIA attributes, alt text, and good contrast.
